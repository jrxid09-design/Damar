# 17 User reachability matrix

Every runtime-reachable record has one disposition: USER_VISIBLE_FEATURE, ADVANCED_OR_FORENSIC, BACKGROUND_ONLY, or INTERNAL_ONLY. HTTP and CLI have the broadest current reach. RuntimeHost and voice are presence/background. Memory, device, provider, integration and runtime status have read models but no new Dashboard surface.

Gaps are typed as SURFACE_GAP, READ_MODEL_GAP, CONTROL_API_GAP, CONFIGURATION_GAP, or OBSERVABILITY_GAP. Machine matrix is in data/canonical_baseline.json.
