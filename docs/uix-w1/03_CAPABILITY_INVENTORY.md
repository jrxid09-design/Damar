# 03 Capability inventory

Canonical records are in data/canonical_baseline.json and data/capability_inventory.json. Records separately classify code, registration, composition, runtime reachability, user reachability, governance, tests, and certification.

High-confidence families: HTTP/control API, RuntimeHost, InteractionBus, Manager, Action/Authority/Capability/Actuation/Verification, memory, plugins/tools, CLI, channels, terminal, recovery, resource governor, vault, and embodied core.

Voice, Mata Dewa, providers, MCP, DCD, and distributed execution are configuration/composition dependent and are marked PARTIAL where evidence requires it.
